Описание
Автотесты для сайта по заказу самокатов. Тесты написаны на Python с использованием Selenium WebDriver и pytest. Отчеты сформированы с помощью Allure

Что тестируется
Нажатие кнопок "Заказать" на главное странице
Заполнение формы заказа
Проверка появления всплывающего окна с сообщением об успешном создании заказа
Проверка нажатия на логотип «Самоката» и последующий переход на главную страницу «Самоката»
Проверка нажатия на логотип Яндексаи последующий редирект главной страницы Дзена

Технологии
Python 3.13
Selenium
pytest
Allure
Mozilla FireFox

Как запустить тесты
Установить зависимости:
pip install selenium pytest

Запустить все тесты:
python -m pytest tests/ -v
python -m pytest tests/ -v --alluredir=allure_results
allure serve allure_results
